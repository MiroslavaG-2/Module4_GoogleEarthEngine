## MB5370 - Introduction to Google Earth Engine

This repository contains the code developed throughout _MB5370 - Introduction to Google Earth Engine_. The module aims to introduce and develop the skills necessary for spatial analysis using Google Earth Engine, a cloud-based geospatial platform designed to analyse environmental data at a global scale.

The repository is organised by workshop, with each one building on the skills needed for geospatial analysis. Workshops 1 and 2 introduce the basics of Earth Engine and JavaScript to support the deployment of analyses, putting these skills into practice through guided exercises. Workshops 3 and 4 build on this foundation by working through problem-based analyses; further detail on each problem and how it was approached can be found within the individual workshop scripts. All data used throughout this module is available directly through the Earth Engine Data Catalog.
